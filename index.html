자동차가 목표까지 가는 법을 스스로 배웁니다
사람이 "여기로 가" 하고 가르치지 않습니다. 자동차가 시도해 보고, 잘하면 보상을 받고, 잘 못하면 페널티를 받습니다. 이걸 반복하면 점점 똑똑해집니다. 이게 강화학습입니다.

보상 그래프 — 학습이 진행될수록 보상이 어떻게 변할까?
이 그래프는 DeepRacer 콘솔의 보상 그래프와 같은 모양입니다. 우상향이면 학습이 잘 되는 중이라는 뜻이에요.

수업 활용 가이드 — 1차시 12~15분 활동

활동 1
2분 무작위 시도 관찰
"무작위로 1번 시도" 버튼을 3~5번 누릅니다. 자동차가 거의 깃발에 도달하지 못함을 확인. → "학습이 없으면 이렇다"는 체감.
활동 2
3분 학습 시키기 — 학습 과정 관찰
"100번 학습" 버튼을 1~2번 누릅니다. 주황색 선(자동차가 방금 시도한 경로)이 초반엔 지그재그로 헤매다가 점점 직선에 가까워지는 모습 관찰. 칸에 그려지는 화살표(학습된 최선 행동)도 차근차근 진화. 보상 그래프도 우상향. 학습 후 "학습된 정책으로 1번 시도"로 깨끗하게 확인.
활동 3
3분 보상 바꾸기 — 벽을 보상으로 주기
먼저 "보상 함수만 기본값으로 복원" 클릭(다른 슬라이더가 변경되어 있을 수 있음) → "초기화" → 슬라이더로 "벽 부딪힘 보상/페널티"를 +5로 (한 걸음 보상/페널티는 -1 유지!) → "100번 학습" → 결과 관찰. 자동차가 깃발보다 벽을 치며 점수를 버는 행동을 선호함. → 보상 함수가 잘못 설계되면 의도와 다른 행동을 배운다는 발견.
확장 활동
2분 보상 해킹 — 걸음마다 점수 주기
먼저 "보상 함수만 기본값으로 복원" 클릭 → "초기화" → 슬라이더로 "한 걸음 보상/페널티"를 +5로 → "100번 학습" → 결과 관찰. 목표에 도착하면 에피소드가 끝나므로, 자동차가 빨리 끝내기보다 움직이며 점수를 더 벌려는 행동을 보일 수 있음. → 보상 함수는 의도가 아니라 숫자로 적힌 이득을 최대로 만든다는 발견.
활동 4
3분 보상 바꾸기 — 목표 보상을 음수로
먼저 "보상 함수만 기본값으로 복원" 클릭 → "초기화" → 슬라이더로 "목표 도달 보상"만 -100으로 (왼쪽 끝, 다른 슬라이더는 기본값 유지!) → "100번 학습" → 학습된 정책으로 시도. 자동차가 깃발 쪽이 아니라 반대 방향으로 도망! 보상이 음수면 자동차에겐 "피해야 할 것"이 됨. → 보상의 부호(+/−)가 행동을 완전히 뒤집는다는 발견.
핵심 발견 정리
3분 학생과 함께 정리
① 학습 없으면 무작위, 학습 후엔 똑똑 — 강화학습의 기본 원리.
② 보상은 행동의 이유 — 페널티를 0으로 만든다고 항상 망가지지는 않지만, 벽이나 걸음에 보상을 주면 자동차는 점수 버는 행동을 배움 (활동 3, 확장 활동).
③ 보상 해킹이 생길 수 있음 — 우리가 바란 행동이 아니라 숫자로 가장 이득인 행동을 배움. 보상 함수 설계가 행동을 만든다.
④ 보상의 부호가 행동을 결정 — 양수면 다가가고, 음수면 도망감 (활동 4).
⑤ DeepRacer도 똑같이 작동한다 — 트랙 위 자동차가 보상 함수에 따라 학습. 이제 다음 차시에서 콘솔로 직접 해 보자!
자동차는 “어느 칸으로 갈지”가 아니라 현재 주행 상황에서 어떻게 조향하고 달릴지를 배웁니다

DeepRacer와의 연결
중요 이 화면은 실제 DeepRacer의 단순화 모델입니다
실제 DeepRacer는 카메라/LiDAR와 신경망을 사용합니다. 이 시뮬레이터는 그 내부를 모두 재현하지 않고, 학생이 보상 함수와 상태-행동 관계를 먼저 이해하도록 단순화했습니다.
이 시뮬레이터AWS DeepRacer로 이어지는 개념
도로 중심에서의 거리distance_from_center, track_width
조향각과 속도 선택steering_angle, speed 기반 action space
트랙 이탈all_wheels_on_track, is_offtrack
앞으로 진행한 정도progress, steps
보상 그래프훈련 중 보상이 좋아지는지 확인하는 지표
활동 1
2분 학습 없이 주행 관찰
"학습 없이 1번 주행"을 눌러 자동차가 무작위 조향/속도 선택을 하면 쉽게 도로 밖으로 나가거나 중심선에서 멀어지는 것을 봅니다.
활동 2
3분 100번 학습 후 정책 실행
"100번 학습" 후 "학습된 정책으로 주행"을 눌러 경로가 더 안정되는지 봅니다. 칸별 화살표가 아니라, 현재 상황에서 조향각과 속도를 고르는 정책이 생긴다는 점을 강조합니다.
활동 3
3분 보상 함수 바꾸기
빠른 속도 보상을 크게 올리고 트랙 이탈 페널티를 약하게 만들면 자동차가 무리하게 달리다 이탈할 수 있습니다. 중심선 보상을 낮추면 도로 안에만 머물러도 충분하다고 배울 수 있습니다.
핵심 정리
정리 보상 함수는 “의도”가 아니라 “점수 규칙”입니다
좋은 DeepRacer 모델은 단순히 도로 위에 있는 차가 아니라, 중심을 유지하고 앞으로 빠르게 진행하며 과한 조향과 이탈을 피하는 차입니다. 학생에게 “어떤 숫자를 주면 어떤 행동을 배울까?”를 묻게 만드는 것이 이 활동의 목적입니다.
